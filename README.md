# SciKI_esur

This repository mainly contains the result of registering studies on urbanization and ecosystem services (from Web of Science Core collection, until 2020) based on a specified Scientific Knowledge Graph (SciKG) schema, which reduces research waste by combining traditional bibliometric analysis and our proposed Scientific Knowledge Integration (SciKI) method.

The current SciKG schema only limits the relations to be the seven relations in SciERC (https://aclanthology.org/D18-1360/). No explicit type constraints on entities.
